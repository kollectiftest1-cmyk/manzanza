## 🚀 POUR DÉMARRER

### Étape 1: Installation Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

### Étape 2: Tester l'API
- Ouvrir http://localhost:8000/api/docs/
- Tester le login
- Explorer les endpoints

### Étape 3: Configurer Frontend
```bash
# À la racine du projet
copy .env.example .env
# Éditer .env avec VITE_API_URL=http://localhost:8000/api
```

### Étape 4: Mettre à jour Redux
- Importer les fonctions de `src/services/api.js`
- Utiliser dans les slices Redux
- Voir exemples dans INTEGRATION_GUIDE.md
