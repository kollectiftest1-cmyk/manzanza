## Mode d’emploi des procédures

Chaque opération ci-dessous indique les rôles autorisés, le chemin d’accès, les étapes à exécuter, le résultat attendu et la conduite à tenir en cas d’erreur. Les intitulés de boutons peuvent varier légèrement entre le Web et le mobile, mais la règle métier reste la même.

Avant toute opération, vérifiez l’environnement utilisé, votre rôle, l’année académique active et la qualité de la connexion. Sur mobile, utilisez l’adresse IP réseau du serveur backend et non localhost.

### 2.1 Configuration Académique - Années Académiques
- **Création Année Académique**
  - 🔹 SGAC, DG, PDG
  - **Chemin d’accès :** Web : Académique > Calendrier ; mobile étudiant/enseignant : Agenda.
  - **Marche à suivre :**
    1. Se connecter avec un rôle autorisé, puis suivre : Web : Académique > Calendrier ; mobile étudiant/enseignant : Agenda.
    2. Appuyer sur Ajouter, Nouveau ou l’action équivalente, puis sélectionner le contexte académique concerné.
    3. Renseigner tous les champs obligatoires, joindre les fichiers demandés et vérifier les dates, montants ou destinataires.
    4. Enregistrer, attendre la confirmation, puis rouvrir la fiche pour vérifier qu’elle apparaît avec le bon statut.
  - **Résultat attendu :** L’opération « Création Année Académique » est enregistrée avec le statut attendu et reste traçable dans le module.
  - **En cas d’erreur :** Conserver les données saisies, vérifier la connexion et les champs signalés, puis réessayer une fois. Si l’erreur persiste, relever le message exact et contacter le responsable du module ou le Service IT.

## 🎯 NOTES IMPORTANTES

### Principe de Hiérarchie
- Chaque niveau peut effectuer les actions approuvées pour tous les niveaux inférieurs
- Les actions marquées ✓ sont conditionnelles (nécessitent justification ou accord)
- PDG a accès à TOUTES les actions avec pouvoir d'approbation final

### Restrictions Spéciales
- **DG :** Pas d'accès à gestion financière complète (sauf lecture)
- **SGAC :** Pas d'accès à gestion financière (sauf coordination académique)
- **Enseignant :** Accès limité à ses cours et étudiants enrôlés
- **Étudiant :** Accès limité à ses propres données académiques

### Profils Sous Tutelle
- Chef de Département peut déléguer création d'utilisateurs à assistant
- Chef de Section peut déléguer tâches administratives à adjoint
- Enseignant peut déléguer correction à assistant
